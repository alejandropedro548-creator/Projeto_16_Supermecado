​⚽ FutDados — Sistema Inteligente de Análise e Desempenho no Futebol
​O FutDados é uma aplicação web desenvolvida em Python utilizando a biblioteca Streamlit. O objetivo do projeto é simular o funcionamento do departamento de análise e inteligência de um clube de futebol profissional, integrando informações entre diferentes áreas da comissão técnica e atletas.
